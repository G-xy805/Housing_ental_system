# 租客信息管理 Spec

## Why
为房屋租赁系统添加租客信息的查看和管理功能，完善左侧菜单导航，提供租客信息的集中管理入口，支持租客信息的快速查询和维护。

## What Changes
- 左侧菜单新增"租客信息管理"入口
- 创建租客信息列表页面
- 实现租客信息详情查看
- 添加租客信息编辑功能
- 实现租客搜索和筛选
- 添加租客历史记录查看

## Impact
- 受影响的功能：租客管理、房源管理、合同管理
- 受影响的代码：前端导航菜单、租客管理页面、后端租客 API

## ADDED Requirements

### Requirement: 左侧菜单扩展
系统 SHALL 在左侧菜单中添加租客信息管理入口
- 菜单项："租客信息管理"
- 图标：用户相关图标
- 权限控制：仅管理员和授权员工可见
- 支持菜单展开/收起

#### Scenario: 访问租客管理
- **WHEN** 用户点击左侧菜单"租客信息管理"
- **THEN** 系统导航到租客信息列表页面

### Requirement: 租客信息列表
系统 SHALL 提供租客信息列表展示功能
- 显示所有租客基本信息
- 支持分页显示
- 显示关键信息：姓名、联系方式、入住状态、合同数量
- 支持按状态筛选（在租、已退租、意向）
- 支持排序（按入住时间、姓名等）

#### Scenario: 查看租客列表
- **WHEN** 用户访问租客管理页面
- **THEN** 系统展示所有租客信息列表

#### Scenario: 筛选租客
- **WHEN** 选择"在租"状态筛选
- **THEN** 系统只显示当前在租的租客

### Requirement: 租客信息搜索
系统 SHALL 提供强大的租客搜索功能
- 按姓名搜索（支持模糊匹配）
- 按手机号搜索
- 按身份证号搜索
- 按房源地址搜索
- 组合条件搜索

#### Scenario: 搜索租客
- **WHEN** 输入姓名关键词
- **THEN** 系统实时过滤显示匹配的租客

#### Scenario: 组合搜索
- **WHEN** 输入姓名 + 选择状态
- **THEN** 系统显示同时满足条件的租客

### Requirement: 租客详情查看
系统 SHALL 提供租客详细信息查看页面
- 基本信息：姓名、性别、身份证号、联系方式
- 紧急联系人信息
- 当前入住房源信息
- 历史合同记录
- 支付记录汇总
- 备注信息

#### Scenario: 查看租客详情
- **WHEN** 点击租客列表中的某一行
- **THEN** 系统展示该租客的完整详细信息

#### Scenario: 查看历史合同
- **WHEN** 查看租客详情
- **THEN** 系统展示该租客的所有历史合同记录

### Requirement: 租客信息编辑
系统 SHALL 提供租客信息编辑功能
- 修改基本信息
- 修改联系方式
- 更新紧急联系人
- 添加/编辑备注
- 记录修改历史

#### Scenario: 更新租客信息
- **WHEN** 管理员修改租客信息并保存
- **THEN** 系统更新租客信息并记录修改时间

### Requirement: 租客状态管理
系统 SHALL 提供租客状态管理功能
- 在租：当前有有效合同
- 已退租：合同到期或终止
- 意向：咨询未签约
- 黑名单：违规租客
- 状态自动更新（基于合同状态）

#### Scenario: 状态自动更新
- **WHEN** 租客合同到期
- **THEN** 系统自动更新租客状态为"已退租"

#### Scenario: 加入黑名单
- **WHEN** 管理员将租客加入黑名单
- **THEN** 系统标记该租客并提示警告

### Requirement: 租客统计分析
系统 SHALL 提供租客统计信息
- 租客总数统计
- 在租/退租/意向数量
- 租客来源分析
- 租客分布（房源类型）
- 趋势图表

#### Scenario: 查看统计数据
- **WHEN** 访问租客管理页面
- **THEN** 系统展示租客统计概览

## 数据模型要求

### 租客信息展示字段
- tenant_id: 租客 ID
- name: 姓名
- gender: 性别
- id_card: 身份证号（部分隐藏）
- phone: 手机号
- email: 邮箱
- emergency_contact: 紧急联系人
- emergency_phone: 紧急联系人电话
- status: 状态（在租、已退租、意向、黑名单）
- current_property: 当前入住房源
- contract_count: 合同总数
- active_contract: 有效合同数
- total_paid: 累计支付金额
- remark: 备注
- created_at: 注册时间
- updated_at: 更新时间

## 技术栈要求

### 前端实现
- **框架**：Vue.js 或 React
- **UI 组件**：Element UI 或 Ant Design
- **表格**：支持分页、排序、筛选
- **图表**：ECharts 或 Chart.js

### 后端实现
- **框架**：Flask
- **ORM**：SQLAlchemy
- **API**：RESTful API
